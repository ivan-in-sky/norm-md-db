# overrides/ — единственное место ручных правок

Файлы в `md/` генерируются конвейером из оригиналов. Всё, что вы исправите там
вручную, будет потеряно при следующей конвертации. Поэтому ручные правки живут
здесь и применяются при пересборке. В рабочем vault (`база/`) этот каталог
называется `правки/` — состав и семантика те же.

```
overrides/
├── <doc_id>.yaml                       # ✅ реализовано: плоские поля фронтмэттера
│                                       #    (--meta-override; статус, темы, verified,
│                                       #    origin_url/publisher → блок source:)
├── symbols/<doc_id>.yaml               # ✅ реализовано: словарь символов-картинок
│                                       #    (--glyphs; правила {sha256, find, repl, note};
│                                       #    в vault: правки/символы-<doc_id>.yaml)
├── comparison/<doc_id>.yaml            # ✅ реализовано: объяснённые расхождения сверки
│                                       #    (compare --explained; {эталон, рабочая, причина};
│                                       #    в vault: правки/сверка-<doc_id>.yaml)
├── formulas/<doc_id>-eqNNN.yaml        # 🔧 фаза 2: выверенный LaTeX формул-картинок
│                                       #    (формат — docs/08-wmf-formulas.md §6)
└── materials/<doc_id>/                 # доказательства ручной верификации
                                        #    (кропы, контактные листы — как в vault правки/материалы/)
```

## Порядок применения

```
источник (.docx/.pdf)
   └─► normconv convert / pdf2md ─► автодетекция метаданных
          └─► overrides/<doc_id>.yaml   (сливается ПОСЛЕ автодетекции —
                │                        ручное побеждает; --meta-override)
                ├─► overrides/symbols/<doc_id>.yaml   (--glyphs: литеральные подстановки)
                └─► md/<Обозначение>.md + catalog/
```

Приоритет: `overrides` > автодетекция > значения по умолчанию.

⚠️ Кэш конвертера считается по **флагам команды**, а не по содержимому
override-файлов: после правки файла в `overrides/` пересборка выполняется с
`--force` (`make convert DOC=<doc_id>` делает это сам).

## Схема и валидация

`schemas/overrides.schema.json`; проверка в CI (workflow `quality.yml`).
