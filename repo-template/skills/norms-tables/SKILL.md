# Значения из таблиц нормативов

Таблицы — главный источник ошибок в RAG по нормативам: в них объединённые ячейки, многоуровневые шапки и единицы измерения, вынесенные в заголовок. Следуй правилам ниже.

## Где брать данные

| источник | что в нём | когда использовать |
|---|---|---|
| `md/<doc_id>.tables.jsonl`, поле `grid` | нормализованная прямоугольная сетка: каждая ячейка со значением, слияния раскрыты | **основной источник** для точного значения |
| `md/<doc_id>.tables.jsonl`, поле `spans` | исходные ячейки с `rowspan`/`colspan` | когда нужно понять структуру шапки |
| `md/<doc_id>.tables.jsonl`, поле `caption` | «Таблица 8.1 — Расчётные сопротивления бетона» | для цитирования |
| HTML `<table>` в `md/` | как выглядит для человека | показывать пользователю, не парсить |
| `index/chunks.atoms.jsonl` | плоский текст таблицы + подпись + пункт | семантический поиск по таблицам |
| CSV (`<doc_id>.tblNNN.csv`) | большие таблицы приложений | программная обработка, фильтрация по сортаменту |

## Алгоритм извлечения значения

1. Найди таблицу: `norms.tables(doc_id)` или поиск по подписи (`grep -n "Таблица 8.1" md/…`).
2. **Прочитай caption целиком** — в нём часто единицы измерения и условия («… в МПа, для бетона классов…»).
3. Определи **полный ключ строки**. В таблицах с многоуровневой шапкой значение определяется не одной колонкой, а комбинацией:
   ```
   grid[строка][колонка] → значение
   ключ строки = значение первой колонки (+ колонки-категории, если она объединена по вертикали)
   ключ колонки = заголовок уровня 1 + заголовок уровня 2
   ```
   В `grid` слияния уже раскрыты: значение объединённой ячейки продублировано во все покрытые позиции, поэтому достаточно взять `grid[r][c]` и заголовки `grid[0][c]`, `grid[1][c]`.
4. **Проверь сноски и примечания к таблице** — они содержат исключения («для бетонов на пористых заполнителях значения умножать на 0,85»).
5. Проверь пункт текста, ссылающийся на таблицу: он задаёт условия применения.
6. Только после этого называй значение.

## Цитирование

```
СП 63.13330.2018, таблица 6.7 (строка «B25», колонка «Rb, МПа (для сжатия)»): 14,5 МПа
```

Обязательно: обозначение документа, номер таблицы, **название** строки и колонки (не их индексы), единицы измерения, сноска/примечание, если они меняют значение.

## Запрещено

- **интерполировать и экстраполировать**: если в таблице нет класса B27 — значения для него нет, а не «примерно между B25 и B30»;
- брать значение без учёта сносок и примечаний к таблице;
- путать колонки при многоуровневой шапке (самая частая ошибка!) — всегда выводи полный путь к колонке;
- называть единицы измерения «на глаз»: только из заголовка таблицы или из пункта текста;
- смешивать значения из разных редакций документа (проверь `amendments` и `status`);
- округлять: приводи значение как в источнике, а округление — отдельной оговоркой.

## Если таблица повреждена при конвертации

Признаки: пустая первая строка, сдвинутые колонки, `n_cols` не совпадает с шириной строк, флаг `has_merged: true` без `verified`. В этом случае:

1. Проверь `<doc_id>.qa.json` → `tables` и `review` (там будет `table` с пометкой «проверить разметку»).
2. Сравни с официальным источником (ссылка в `source.uri`).
3. В ответе укажи: «значение взято из непроверенной конвертации таблицы N, сверьте с официальным изданием».
4. Заведи issue «Ошибка в документе» с описанием расхождения.

## Пример полного разбора

Вопрос: «Расчётное сопротивление бетона B25 на сжатие по СП 63.13330.2018?»

```python
tables = [json.loads(l) for l in open("md/sp-63-13330-2018.tables.jsonl", encoding="utf-8")]
t = next(t for t in tables if "6.7" in t["caption"] or "Расчетные сопротивления" in t["caption"])
header_top, header_sub = t["grid"][0], t["grid"][1]
row = next(r for r in t["grid"] if r and r[0].strip() == "B25")
# найти колонку Rb: заголовок содержит "Rb" и "сжати"
col = next(i for i, h in enumerate(header_top) if "Rb" in h)
value, units = row[col], header_sub[col]
```

Ответ: «СП 63.13330.2018 (с изм. № 1–3, действует), таблица 6.7 — Расчётные сопротивления бетона осевому сжатию: для класса B25 `Rb = 14,5 МПа`. Примечание к таблице: значения приведены для тяжёлого бетона; для других видов — см. таблицы 6.8–6.11».
