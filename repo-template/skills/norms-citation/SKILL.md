# Цитирование нормативных требований

## Обязательный формат

    <обозначение> «<название>», п. <номер>[, с. <страница>]
    (<статус>[, с изменениями № …])

Пример:

    СП 63.13330.2018 «Бетонные и железобетонные конструкции. Основные положения»,
    п. 8.1.6, с. 112 (действует, с изм. № 1–3)

Данные для ссылки берутся из чанка: `designation`, `title`, `amendments`,
`clause`, `pages`, `status`. Номер страницы — из `pages` (привязка к изданию);
если её нет — цитировать без страницы.

## Правила

1. Никогда не пиши «согласно СП» без обозначения и года.
2. Если у документа `status: superseded` — укажи это явно и дай замену из
   поля `superseded_by`. Требование из отменённого документа можно приводить
   только если вопрос про исторический объект.
3. Если `status: unknown` — добавь оговорку «статус документа не сверен с
   реестром».
4. Если `verified: false` или `confidence < 0.95` — добавь оговорку
   «по непроверенной конвертации, сверьте с официальным источником».
5. Если пункт исключён изменением (`excluded_clauses` во фронтмэттере,
   callout `> [!warning] … исключены …` в тексте) — требование НЕ действует;
   процитируй факт исключения с датой и номером изменения.
6. Формулы приводи в LaTeX как в источнике, с расшифровкой обозначений из
   «где»-блока. Не пересказывай формулу словами. Если формула в источнике
   осталась картинкой (`<img … .wmf>`) — так и скажи: «формула в базе не
   расшифрована, см. официальное издание»; NEVER не выдумывай LaTeX.
7. Значения из таблиц приводи с указанием строки и колонки (названием, а не
   номером): «Таблица 8.1, колонка „Класс бетона B25“, строка „Rb“». Не
   интерполируй значения между строками/колонками.
8. Если в корпусе нет ответа — так и скажи. Не выдумывай номера пунктов.
9. Давай кликабельную ссылку на первоисточник:
   - в vault/Obsidian: `[[<Обозначение>#^c8-1-6]]`;
   - в веб/GitHub: строку и ссылку возьми из `catalog/CLAUSES.jsonl`
     (поля `line`, `block_id`, `anchor`).

## Проверка перед отправкой

- [ ] у каждой ссылки есть обозначение + год + пункт
- [ ] статус документа сверен с catalog (или дана оговорка про unknown)
- [ ] нет требований из superseded/исключённых пунктов без оговорки
- [ ] нет формул, которых не было в найденных чанках
- [ ] непроверенные документы (`verified: false`) помечены
