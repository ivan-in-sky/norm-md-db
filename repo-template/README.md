# stroy-norms

Корпус нормативных документов строительства (СП, СНиП, ГОСТ, ГОСТ Р, РД, МДС, ВСН, сметные нормативы) в каноническом Markdown — для людей и для RAG-агентов.

> ⚠️ **Не является официальной публикацией.** Тексты получены автоматической конвертацией из
> официальных источников и могут содержать ошибки. Для юридически значимых решений используйте
> официальные источники: сайт Минстроя России и ФАУ «ФЦС», ФГИС СТ Росстандарта,
> pravo.gov.ru. Правовой статус материалов — в [`NOTICE.md`](NOTICE.md).


## Статусы документов

| статус | что означает | доверие |
|---|---|---|
| `verified` | вычитан человеком: таблицы, формулы, номера пунктов сверены с оригиналом | высокое |
| `converted` | сконвертирован автоматически, есть QA-отчёт, возможна очередь ручной доработки | среднее — в ответе делается оговорка |
| `superseded` | отменён / заменён | только для исторических справок |
| `unknown` | статус не сверен с реестром | требуется проверка |

Каждый документ несёт `conversion.confidence` (0–1) и список `review_items` в `<doc_id>.qa.json`.

## Как добавить документ

1. Положите файл в `inbox/` (или откройте issue «Добавить документ» со ссылкой на официальный источник).
2. CI сконвертирует его и откроет PR с QA-отчётом.
3. Пройдите по чек-листу `<doc_id>.qa.md`, правки вносите в `overrides/<doc_id>.yaml` — **не в `md/`**.
4. После вычитки поставьте `verified: true` в overrides.

Подробнее: [`CONTRIBUTING.md`](CONTRIBUTING.md).

## Как сообщить об ошибке

Issue «Ошибка в документе» с указанием `doc_id`, номера пункта и ссылки на официальный текст. Ошибки в требованиях (числа, единицы, классы) — приоритет P1.

## Устройство проекта

| каталог | что это |
|---|---|
| `md/` | канонический текст + QA-отчёты — **единственный источник истины** |
| `catalog/` | производный каталог (jsonl/csv/yaml/INDEX.md) |
| `overrides/` | **единственное** место ручных правок метаданных и формул |
| `sources/` | реестр оригиналов (сами файлы — в object storage) |
| `tools/` | конвертер `normconv`, линт, чанкер, индексация, MCP-сервер |
| `skills/` | навыки для агентов |
| `schemas/` | JSON Schema контракты данных |
| `evals/` | golden-эталоны конвертера + вопросы для RAG-evals |
| `docs/` | проектная документация: архитектура, конвертация, хранение, право |
