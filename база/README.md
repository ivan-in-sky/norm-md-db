# База строительных нормативов (Obsidian + RAG)

Практическая база действующих редакций СП, СНиП, ГОСТ, РД — для строителей и
проектировщиков. Открыта как vault Obsidian; параллельно из неё собирается
RAG-индекс для локального агента.

> ⚠️ **Не является официальным изданием.** Тексты получены автоматической
> конвертацией и могут содержать ошибки. Для юридически значимых решений
> используйте официальные источники: ФАУ «ФЦС» (faufcc.ru), Минстрой России,
> ФГИС СТ Росстандарта, pravo.gov.ru.

Алгоритм ведения базы (для агента): `normconv/docs/10-local-agent.md`
(самодостаточный ранбук) и сводка `normconv/AGENTS.md`. Этот файл —
**единственное место, где фиксируется текущее состояние** (документы ниже
описывают процесс и не устаревают).

## Папки

| папка | что внутри | кто трогает |
|---|---|---|
| `документы/` | заметки нормативов: `<Обозначение>.md` + QA-отчёты, таблицы, страницы, картинки; `_reports/` — дашборд и отчёты сверки | конвейер; руками — только через `правки/` |
| `каталог/` | `INDEX.md` — список всех документов; `CLAUSES.md` — указатель пунктов; `catalog.*` | пересобирается автоматически |
| `источники/` | оригиналы файлов (docx/pdf/сканы) + `inventory.csv` (16 колонок провенанса) | только чтение |
| `входящие/` | транзитная зона: только что скачанное | агент |
| `индекс/` | `chunks.jsonl` (+atoms, +stats) — нарезка для RAG (кэш, пересобирается) | конвейер |
| `правки/` | overrides: `<doc_id>.yaml` (мета-поля), `символы-<doc_id>.yaml` (словарь глифов), `сверка-<doc_id>.yaml` (объяснённые расхождения), `материалы/` (доказательства верификации) | человек и агент |
| `актуальные-версии.yaml` | реестр: какая редакция действующая, чем что заменено | агент + человек |

## Как устроены ссылки

- В текстах — вики-ссылки **без года**: `[[ГОСТ 31937]]`, `[[СП 22.13330]]`.
  Они ведут на **действующую редакцию** через алиасы заметок и реестр.
- **Красная ссылка** = документ ещё не добавлен в базу (кандидат на скачивание).
- Алиасы заметки содержат старые обозначения: `[[СНиП 2.02.01-83]]` приведёт
  на `СП 22.13330.2016`.
- Точная ссылка на пункт: `[[СП 22.13330.2016#^c8-1-6]]` (block ID); готовые
  ссылки на строки — в `каталог/CLAUSES.md`.

## Как читать отметки в тексте

| отметка | смысл |
|---|---|
| `> [!warning] Опечатка в официальном тексте` | так в источнике; опечатка сохранена как факт |
| *(абзац введён Изменением N 2, утв. Приказом…)* | происхождение правки — изменение включено в текст |
| `> [!warning] Пункты 10.10–10.21 исключены с 08.01.2024` | требование больше не действует |
| `<img … .wmf>` | формула-картинка, ещё не расшифрована (очередь в `.qa.md`, план — `normconv/docs/08-wmf-formulas.md`) |
| `$\gamma_n$` и т.п. | символ восстановлен словарём из `правки/символы-*.yaml` |

## Порядок добавления документа

Полный алгоритм — `normconv/docs/10-local-agent.md` §3 (мастер-алгоритм) и
Приложение B (готовые команды четырёх реальных документов). Коротко:

```
разведка (действующая редакция, статус)
→ скачать → входящие/ → probe → источники/ (+inventory.csv)
→ конвертация (--registry актуальные-версии.yaml --license «официальный документ (ГК РФ ст.1259 п.6)»)
→ вендор-очистка и вики-ссылки (автоматически) → вендор-grep
→ эталон: compare (покрытие ≥ 0.95, rc=0) + pages
→ lint (0 ошибок) → QA-очередь → статус в правки/
→ пересборка: chunk, catalog, clauses, report
```

Пересборка производных (после любого изменения заметок):

```bash
cd <корень проекта> && export PYTHONPATH=normconv/tools
python3 -m normconv.cli chunk   база/документы --out база/индекс/chunks.jsonl
python3 -m normconv.cli catalog база/документы --out база/каталог
python3 -m normconv.cli clauses база/документы --out база/каталог/CLAUSES.md
python3 -m normconv.cli report  база/документы
python3 -m normconv.cli lint    база/документы      # гейт: error: 0
```
