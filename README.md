# norm-md-db — база действующих редакций строительных нормативов

Канонические Markdown-документы (СП, СНиП, ГОСТ, ГОСТ Р, РД…) для **Obsidian** и **RAG**:
один норматив = одна папка с `.md` + `assets/`, формулы — LaTeX inline, таблицы — inline,
ссылки между документами — алиасы без года.

> ⚠️ Это **не юридический продукт и не официальное издание**. Тексты сверены с официальными
> источниками (реестр — [`data/inventory.csv`](data/inventory.csv)); статус действия каждого
> документа — во фронтмэттере (`status:`) и в каталоге.

## Структура

```
data/                  # нормативные документы по категориям (сп/, гост/, …)
  <категория>/<ОБЗ>/   # папка = документ: <ОБЗ>.md + assets/
  registry.yaml        # реестр обозначений → doc_id (резолвинг ссылок)
  inventory.csv        # provenance: файл, sha256, URL источника
CATALOG.md             # каталог всех документов (сгенерирован)
docs/format.md         # контракт формата данных (спецификация .md-файлов)
tools/                 # конвейер конвертации и производных артефактов
```

## Как пользоваться

**Obsidian.** Откройте `data/` как vault (или добавьте в существующий). Вики-ссылки
`[[ГОСТ 27751]]`, `[[СП 22.13330#^c8-1-6]]` резолвятся по алиасам во фронтмэттере —
ссылка без года всегда ведёт на действующую редакцию, даже если документ переименован.

**RAG.** Чанки: `PYTHONPATH=tools python -m normconv.cli chunk data --out .tmp/chunks.jsonl`
(границы чанков — структура документа, не произвольные токены). Минимальный контракт
цитаты и правила поиска — [`docs/format.md`](docs/format.md) §14.

**Человеку.** Начните с `CATALOG.md`; точные строки пунктов — в производном указателе
`CLAUSES.md` (генерируется из базы).

- Код и документация: **MIT** (`LICENSE`).
- Тексты нормативных документов: **официальный документ (ГК РФ ст. 1259 п. 6)** —

  назначению базы (чтение, цитирование с указанием источника).
