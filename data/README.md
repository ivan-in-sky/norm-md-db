# База строительных нормативов — данные

Действующие редакции СП, ГОСТ (и далее СНиП) в каноническом Markdown:
текст с формулами (LaTeX), таблицами и рисунками. Не официальное издание —
для юридически значимых решений сверяйтесь с официальными источниками.

## Как пользоваться

- **Obsidian:** откройте эту папку (`data/`) как vault — ссылки, формулы и таблицы
  работают из коробки. Или перенесите нужную папку документа в свой vault:
  она самодостаточна (markdown + `assets/` с картинками).
- **RAG / обработка:** текст чистый UTF-8 Markdown; нарезка по пунктам — по block ID
  (`^c…`) и заголовкам. Формат описан в [`docs/format.md`](../docs/format.md).

## Структура

```
сп/СП 22.13330.2016/
├── СП 22.13330.2016.md    # документ: frontmatter + тело
└── assets/                # рисунки и формулы-картинки (если есть)
```

Категории: `сп/` — своды правил, `гост/` — ГОСТ и ГОСТ Р. Имя папки = обозначение
с годом; внутри один markdown с тем же именем.

## Ссылки между документами

В тексте — вики-ссылки без года: `[[СП 22.13330]]`, `[[ГОСТ 31937]]`. Они ведут на
действующую редакцию (резолвинг по `aliases` во фронтмэттере и `registry.yaml`).
Красная ссылка = документ ещё не в базе. Точная ссылка на пункт:
`[[СП 22.13330.2016#^c8-1-6]]`.

## Статусы и отметки

| отметка | смысл |
|---|---|
| `status: active` / `verified` во фронтмэттере | редакция действует / вычитана человеком |
| `> [!warning] Опечатка в официальном тексте` | так в источнике, сохранено как факт |
| *(абзац введён Изменением N …)* | изменение включено в текст |
| `<img src="assets/…wmf/png">` | формула-картинка, ещё не расшифрована в LaTeX |

## Состав и происхождение

- `CATALOG.md` — каталог корпуса (генерируется).
- `registry.yaml` — действующие редакции и замены.
- `inventory.csv` — реестр источников: sha256 и URL каждого файла, из которого
  сделана конвертация (сами файлы в репозиторий не входят).
