# Разметка нормативных документов (normconv)

Полная спецификация с примерами: `docs/11-markup.md` (относительно корня
репозитория). Этот скилл — рабочая памятка: ключевые правила + алгоритм.

## Когда применять

- доработка заметок `база/документы/*.md` (элемент за элементом);
- проверка разметки после конвертации;
- создание/правка элементов: пунктов, таблиц, формул, рисунков, примечаний.

## Ключевые правила (шпаргалка)

1. **Заголовки**: H1 = заголовок документа (один); H2 = разделы (Предисловие,
   Введение, 1…N, «Использованные нормативные документы», приложения);
   H3 = x.y; H4 = x.y.z. Приложение — одним предложением:
   `## Приложение М — Основные буквенные обозначения`.
2. **Пункт**: номер обычным текстом (НЕ жирный) + `^c6-7-12` в конце первого
   абзаца. Перечисления — подряд, без пустых строк.
3. **Формула**: `$$…\tag{6.25}$$` + `^eNNN` отдельной строкой; «где»-блок —
   одно обозначение на строку.
4. **Символы в тексте — только LaTeX**: `$R$`, `$\varphi_{II}$`, `$c_{II}$`,
   `$t_1$`. Римские I/II для групп предельных состояний. `<sub>`/`<sup>` в
   тексте не допускаются.
5. **Таблица**: подпись `Таблица N — Название` (один абзац, без жирного) +
   `^tNNN` + `<table>`. Внутри ячеек LaTeX НЕ рендерится → `<i>`, `<sub>`,
   юникод: `<td><i>M</i><sub><i>q</sub></td>`.
6. **Рисунок**: `<img alt="содержательное описание">` + `Рисунок N — Название` +
   `^fNNN`; пометка о редакции — blockquote `> *(рисунок 9.1 в ред. …)*`;
   flowchart → mermaid.
7. **Примечание**: `> **Примечание** — …` (несколько — нумерованные, отдельные
   blockquote).
8. **Ссылки**: пункт `[6.7.8](файл.md#^c6-7-8)`, раздел `[5.6](файл.md#якорь)`,
   таблица/формула/рисунок через `#^t…/#^e…/#^f…`, библиография
   `[2](файл.md#^biblio-2)`, другой документ — `[[ГОСТ 27751]]`.
   `(см. 6.9)`, `(рисунок 6.14)` — всегда ссылкой.
9. **Запрещено**: HTML-комментарии, ≥2 пустых строки подряд, жирные номера
   пунктов, разорванные подписи, `alt=""`, `<sub>` вне таблиц, Word-артефакты.

## Алгоритм доработки (элемент за элементом)

1. **Парсинг**: разбить документ на элементы по block ID и структуре
   (заголовки, пункты, перечисления, таблицы, формулы+«где», рисунки,
   примечания, библиография).
2. **Проверка каждого элемента** по чек-листу из `docs/11-markup.md` §13.
3. **Сверка с доверенным источником** (приоритет): официальный PDF (рендер
   страниц) > текстовый слой PDF > экспорт СПС. Расхождение → QA.
4. **Правка in place**; синхронизировать `<doc_id>.tables.jsonl` и фронтмэттер
   `stats`.
5. **Гейт**: `PYTHONPATH=tools python -m normconv.cli lint "база/документы/<файл>.md"`
   → `error: 0`.
6. **Фиксация** в `<doc_id>.qa.md` и `наработки/журнал-обкатки.md`.

## Инструменты

- рендер страниц PDF для сверки — `pypdfium2` (скрипты в `.tmp/`);
- WMF→PNG — PowerShell `System.Drawing` (`.tmp/batch_wmf.ps1`);
- vision-распознавание — контактные листы (PIL) + чтение изображений;
- временные файлы — только в `.tmp/` (gitignore).
