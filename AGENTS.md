# AGENTS.md — памятка агента, работающего с этой базой

> Сводная точка входа. Полный исполнительный ранбук —
> [`docs/10-local-agent.md`](docs/10-local-agent.md) (самодостаточный: окружение,
> форматы, команды, пороги, ветки отказов). Остальные `docs/` — справочники и
> обоснования. Состояние базы (что добавлено, что в очереди) — только в
> `база/README.md` и `база/каталог/INDEX.md`, здесь оно не дублируется.

## Что это

База действующих редакций строительных нормативов (СП, СНиП, ГОСТ, ГОСТ Р, РД…)
в каноническом Markdown для **Obsidian + RAG**. Не юридический продукт и **не
официальное издание**. Язык базы и общения — русский.

## Где что лежит

| путь | что |
|---|---|
| `база/` | рабочий Obsidian-vault: `входящие/ источники/ документы/ каталог/ индекс/ правки/` + `актуальные-версии.yaml` |
| `tools/normconv/` | конвертер (python-пакет): docx2md, pdf2md, obsidian-слой, meta, lint, chunker, catalog, clauses, compare |
| `docs/00…10` | документация; **10 — главный ранбук**; 01 — формат Markdown/фронтмэттера; 08 — формулы-картинки; 09 — OCR-сканы |
| `example/` | синтетический эталон: `sample.docx` + полные результаты конвейера |
| `repo-template/` | скелет публикационного репозитория (фаза 2 — публикация) |
| `база/_work/` | рабочая зона: эталонные извлечения официальных PDF (gitignore; воспроизводимы из `база/источники/`) |

## Золотые правила

1. **Только актуальные редакции**, изменения включены в текст; отдельные
   заметки-«изменения» не заводятся. Маркеры *(абзац введён Изменением N …)* —
   нейтральный факт, сохраняются.
2. **Ссылки — беспроигрышные алиасы**: `[[ГОСТ 31937]]`, не `[[ГОСТ 31937-2011]]`.
   Резолвинг — `актуальные-версии.yaml` + `aliases` заметок. Красная ссылка =
   очередь на скачивание, это нормально.
3. **Никаких упоминаний справочных систем** (КонсультантПлюс/Техэксперт/Кодекс/
   cntd/Гарант) в тексте заметок. Провенанс — только `vendor:`/`publisher:` во
   фронтмэттере и `источники/inventory.csv`; файлы `.qa.md` фиксируют факт
   экспорта в счётчиках — это штатно. Проверка по заметке (шаблон намеренно не
   включает голое «кодекс»/«гарант» — ложные срабатывания на «Градостроительный
   кодекс» и «гарантирующих»):
   `grep -inE 'консультант|техэксперт|cntd|login\.consultant|ИС (\"|«)?Кодекс|СПС .{0,2}(Кодекс|Консультант|Техэксперт)|АО (\"|«)?(Кодекс|Техэксперт)|ярлык.{0,3}(\"|«)?Примечания|Примечание изготовителя|Документ предоставлен|Внимание! (Документ включен|О порядке применения)' <заметка>.md`
   → допустимы только строки фронтмэттера.
4. **Оригиналы неприкосновенны** (`источники/` — только чтение). Ручные правки —
   **только** через `правки/` (три типа файлов: мета-override `<doc_id>.yaml`,
   словарь `символы-<doc_id>.yaml`, объяснённая сверка `сверка-<doc_id>.yaml`).
   Правка в заметке напрямую будет затёрта пересборкой.
5. **Официальный PDF — эталон для сверки и страниц**, не источник текста
   (ABBYY теряет индексы формул). Исключение — путь A: docx нет вовсе.
6. **`verified` ставит только человек.** Агент готовит факты и очередь.
7. **Детерминизм**: пересборка того же источника с теми же флагами меняет только
   `converted_at`. После изменения `правки/` пересобирать с `--force`.

## Цикл на один документ (сжато; детали — docs/10)

Многоэтапная доработка документа (stages A/B/C): план + статус — в
`наработки/журнал-обкатки.md` (или отдельный файл), **коммит после каждого этапа**;
возобновление новой сессии — только по файлу состояния + `git log`, не по чату.

```
разведка (действующая редакция R, статус)
→ скачать (sha256 + строка в inventory.csv; текстовый источник И pdf-эталон)
→ входящие/ → probe → источники/<имя>
→ конвертация:
   docx:  python3 -m normconv.cli convert <файл> --out база/документы --jobs 1 \
            --license "официальный документ (ГК РФ ст.1259 п.6)" \
            --registry база/актуальные-версии.yaml --source-uri <url> \
            [--glyphs …] [--meta-override …] [--force]
   pdf:   python3 -m normconv.pdf2md <файл> --out база/документы \
            --registry база/актуальные-версии.yaml \
            --license "официальный документ (ГК РФ ст.1259 п.6)" \
            --source-uri <url> [--glyphs …] [--meta-override …]
→ вендор-grep (правило 3)
→ эталон: pdf2md <офиц.pdf> --out <refdir>; compare compare (--explained при
   перенумерациях) → _reports/; compare pages → pages.json
→ lint база/документы  →  ГЕЙТ: error: 0
→ QA-триаж по <заметка>.qa.md; статус → правки/<doc_id>.yaml
→ производные (порядок фиксирован):
   python3 -m normconv.cli chunk   база/документы --out база/индекс/chunks.jsonl
   python3 -m normconv.cli catalog база/документы --out база/каталог
   python3 -m normconv.cli clauses база/документы --out база/каталог/CLAUSES.md
   python3 -m normconv.cli report  база/документы
→ отчёт: строка CHANGELOG + сводка (confidence, review_items, красные ссылки)
```

## Пороги и гейты

| проверка | норма |
|---|---|
| `lint` | `error: 0`; штатные warnings: `fm_status_unknown`, `low_confidence` |
| `compare` с эталоном | rc=0, покрытие пунктов ≥ 0.95; потери — только объяснённые (`--explained`) или исключённые изменением |
| confidence | ≥ 0.95 зелёный; 0.8–0.95 очередь; < 0.8 обязательный триаж (что в review и почему) |
| вендор-grep | пусто в теле |
| inventory | sha256 + origin_url на каждый файл |

## Формат заметки (минимум; спецификация — docs/11, скилл normconv-markup)

- имя файла = обозначение кириллицей (`СП 22.13330.2016.md`); `doc_id` — латиница;
- заголовки: H1 = заголовок документа, H2 = разделы/приложения, H3 = x.y;
- пункт: `8.1.6 текст… ^c8-1-6` (номер **не** жирный; block ID — стабильный ключ
  всего: ссылки, чанки, указатель CLAUSES); таблица `^t…`, формула `^e…`
  (`\tag{…}`), рисунок `^f…`, библиография `^biblio-…`;
- символы в тексте — только LaTeX; внутри HTML-таблиц — `<i>/<sub>` + юникод;
- таблицы со слияниями — HTML `<table>` + сетка в `.tables.jsonl`;
- формулы — `$$…$$` LaTeX с confidence в QA; нераспознанная формула — картинка
  и очередь `docs/08` (никогда не выдумывать LaTeX);
- примечания — `>`-цитаты; опечатки источника — `> [!warning] Опечатка в
  официальном тексте`; исключённые пункты — `> [!warning] … исключены …` +
  `excluded_clauses` во фронтмэттере;
- `license: официальный документ (ГК РФ ст.1259 п.6)` — для всех нормативных
  текстов (CC0 к ним неприменима: мы не правообладатель).

## Точки участия человека

1. верификация словаря формул/символов (ошибка в словаре системна);

3. подтверждение спорного статуса действия документа.
